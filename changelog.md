# Changelog

## 1.0.0

- Refined the 1.0.0 palette into a more vivid blossom-inspired look with richer sakura pinks, petal ivory, peach, and warm bark tones while keeping the theme non-neon.
- Renamed the theme to CherryBlossom.
- Reworked the app UI from neon pink to softer pastel cherry-blossom pink.
- Removed blue and purple syntax accents in favor of pastel pink, tan, peach, cream, and warm brown.
- Added comprehensive styling for the standard CodeMirror/Lezer highlighting tag vocabulary.
- Added distinct colors for namespaces and class/type names such as `PluginBase`.
- Added dedicated styling for strings, characters, regex, escapes, integers, floats, booleans, null, constants, variables, properties, functions, operators, brackets, metadata, Markdown content, and diagnostics.
- Kept all comment types italic with warm muted tones.
- Added a one-time “Thank you for installing CherryBlossom” dialog using Acode's first-install initialization flag.
- Added a pixel-art cherry blossom icon.
